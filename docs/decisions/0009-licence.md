# 0009 — Licence

Date: 2026-10-25

GPL-3.0-or-later. The Windows executable bundles GNU Wget, which is GPL-3.0, and a copyleft licence keeps the program and every modified copy free to use, study, share and change on the same terms. The copyright line names "WGMDownloader contributors" and credits Claude (Anthropic) as the author: a licence has to be granted by the rights holder, and Claude can't hold copyright.

Rejected: MIT/Apache-2.0 (permissive; would allow closed redistributions of the tool).
